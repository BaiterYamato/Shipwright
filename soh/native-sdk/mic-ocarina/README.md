# Mic Ocarina 0.2.0

Standalone mod for Link-Span / Shipwright OoT. Includes the remake-inspired ocarina interface and microphone input.

## Interface

- Parchment sheet music, notes with controller buttons and confirmation of the recognized song.
- Songbook with the songs learned in the save and their sequences.
- Microphone: capture indicator, actual volume level, note/frequency and pitch history.
- The device opens in the background, keeping the game responsive. Audio is converted from the microphone's format to the detector's original format.
- In-game text is in English.
- Options are under Mods > Mic Ocarina > Ocarina & Audio.
- Open ocarina opens the instrument Link already owns; the panel reports capture status and any refusals.

## Nintendo controls

Open the ocarina normally, including through Dynamic Movement Remake's left D-pad shortcut.

| Button | Action |
| --- | --- |
| L / R / A / Y / X | D4 / F4 / A4 / B4 / D5 notes |
| ZL | Open/close the songbook during free play |
| + | Start the microphone; with capture active, restart the phrase |
| - | Toggle audio practice without activating song effects |
| B | Cancel and put away the ocarina |

The Zelda's Lullaby sequence becomes **Y X A Y X A**. Buttons are read by physical SDL position; glyphs use the Nintendo names from the references.

In version 0.2.1, Y is also filtered in the screen's cancellation logic, in addition to the audio note input. This prevents the B attack binding used by dynamic movement from closing the instrument when playing Y. Physical B still cancels, and normal bindings are restored when leaving this logic.

Without a gamepad, the game's virtual controls remain: A/C for notes, Z for the songbook, Start for microphone/reset and L for practice. The HUD displays these commands. The menu also offers actions to start capture, practice and reset.

## Compatibility

- Native extension package ABI 1.3, restricted to the executable whose SHA-256 is in the manifest generated by CMake.
- Build with OotNativeSdk.cmake and HOST_EXECUTABLE from the same host.
- Its own resources are mounted by the provider without replacing other mods' global textures.
- Dynamic Movement Remake 0.2.13 yields R/X and its shortcuts to the ocarina; it retains the camera continuity fix.
- The native renderer continues running recognition, timers, dialogs and song effects. Only the music screen's drawing commands are replaced.
- Third-party ocarina mapping mods may conflict when reading the same buttons. The remake controls option can be disabled.
- The Windows default microphone must be enabled for desktop apps. Capture starts only after an explicit action; B or putting away the ocarina releases the device.

## Audio recognition

The existing detector continues using YIN, a noise filter, relative contour and merging notes split by vibrato/breathing. Range: 80 to 2400 Hz. Hum or whistle the sequence; approximately one second of silence ends the phrase. Only songs accepted by the game at that moment are submitted.

Reset clears the phrase and history on the capture thread. Practice keeps the feedback, consuming results without sending songs to the game.

## Validation

CTest includes the original detector, actual 48 kHz stereo audio conversion, slow opening/cancellation and regressions for mapping, renderer state preservation, dialogs, keyboard, songbook, practice, reset and the HUD drawing limit. Device availability and physical controller response require a hardware playtest.

## Origin

The detector was ported from the previously supplied MicOcarina.cpp prototype. The interface uses original artwork generated by tools/generate-ocarina-hud-assets.ps1; the reference images are not distributed in the package.
