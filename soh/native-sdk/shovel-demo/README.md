# Pá de demonstração (OoT)

Mod independente para provar os contratos novos do Link-Span no OoT:
preflight de assets, item com chave estável, uso pelo Link criança e registro
V2 com dono. O ícone e o modelo do Martelo Megaton são provisórios, pois este
pacote não distribui assets de terceiros. Ele **não** é uma cópia da pá do
Skijer nem pretende ser um mod de gameplay final.

Com o NEI carregado, o demo concede a pá do próprio NEI. Ela aparece na segunda
página do inventário, na última linha, e pode ser equipada pelo menu. Uma pá
provisória já equipada por uma versão anterior do demo é trocada pela pá do NEI.
Sem o NEI, o demo mantém seu item independente no botão C: em solo firme, cada
uso cria uma rupee verde à frente do Link. Esse item independente não tem célula
de inventário. O ícone e o modelo provisórios continuam inadequados para uma
partida principal.
